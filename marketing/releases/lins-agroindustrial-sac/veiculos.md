## Ordem de abordagem recomendada

1. **Jornal Cana + Novacana** — específicos do sucroenergético, alta relevância para o segmento da Lins
2. **TI Inside + IT Forum** — maior audiência de CIOs/gestores de TI, cobrem SAP com regularidade
3. **Notícias Agrícolas + AgroFoco** — volume de acesso no agro, receptivos a cases com dados
4. **SAP News Center** — via time de parceiros SAP, credibilidade alta mas processo interno
5. **Exame / Valor** — difícil acesso direto, mas alto impacto se publicar

---

## Observações

- **Jornal Cana e Novacana**: foco 100% sucroenergético — usar variante de pitch para agronegócio
- **TI Inside e IT Forum**: usar variante para TI corporativa, destacar redução de 90% e integração de dados
- **SAP News Center**: exige aprovação interna SAP — contatar o time de parceiros da Solveplan para submeter
- **Valor Econômico**: raramente aceita release direto — assessoria de imprensa facilita o acesso
