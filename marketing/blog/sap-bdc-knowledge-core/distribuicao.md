# Distribuição — SAP BDC Knowledge Core

## Post LinkedIn

---

O SAP Knowledge Graph sabe como o ERP funciona.

O SAP Business Data Cloud é o que faz ele saber como o **seu** ERP funciona.

Essa diferença define o teto de qualquer agente SAP no seu ambiente.

O Knowledge Graph é genérico — compartilhado por todos os clientes SAP. Ele carrega 50 anos de engenharia ERP, 452 mil tabelas, 7,3 milhões de campos mapeados. Mas ele não sabe que a empresa Brasil do seu grupo se chama BUKRS 1000, que o fechamento acontece no dia 5 e que lançamentos acima de R$ 50k precisam de aprovação do controller regional.

Quem traz esse contexto é o SAP BDC.

A SAP chama isso de Knowledge Core — *"the trusted knowledge core for every enterprise application and agent"*.

O que está dentro dele:

→ Hierarquias organizacionais reais — entidades, consolidações, estrutura do grupo
→ Dados mestre unificados — clientes, fornecedores, materiais, centros de custo sem duplicação
→ Data products certificados pelo SAP Master Data Governance
→ SAP Domain Models — que traduzem diferença numérica em significado de processo
→ Fontes externas integradas com a mesma semântica de negócio

Um agente com BDC bem estruturado entende o negócio. Um agente sem essa fundação entende os dados — que é muito diferente.
