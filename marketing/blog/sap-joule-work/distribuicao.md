# Distribuição — SAP Joule Work

## Post LinkedIn

---

O SAP sempre foi poderoso. O problema é que operar ele exigia especialistas.

O Joule Work muda isso.

Em vez de navegar entre módulos, transações e menus, o usuário descreve o que precisa em linguagem natural — e o Joule coordena os agentes, busca os dados e executa.

"Prepare o relatório de variação de custo do trimestre para as plantas do Brasil."
"Mostre os pedidos de compra acima do limite de aprovação pendentes desde segunda-feira."
"Inicie o processo de fechamento das entidades do grupo para abril."

Não é sugestão. É execução — dentro dos controles de acesso e aprovação configurados para cada papel.

O que mudou em relação ao Joule anterior:

→ V1: copiloto — respondia perguntas, o usuário executava
→ Joule Work: workspace operacional — o Joule executa, com trilha de auditoria

Três novidades que vale destacar:

→ Suporte a MCP e A2A — interoperabilidade com agentes de terceiros, fora do ecossistema SAP
→ Voz com LiveKit — para quem trabalha longe de um teclado: chão de fábrica, logística, campo
→ Disponível no SAP Datasphere — usuários de analytics consultam e executam em linguagem natural

A ressalva que ninguém menciona: o Joule Work é tão preciso quanto o contexto que o alimenta. Sobre dados fragmentados, a linguagem natural entrega respostas fragmentadas. Sobre um Datasphere bem estruturado e alimentado pelo SAP BDC, entrega respostas que fazem o negócio andar.
