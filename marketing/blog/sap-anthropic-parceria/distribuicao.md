# Distribuição — Parceria SAP e Anthropic

## Post LinkedIn

---

A SAP escolheu o Claude da Anthropic como modelo de raciocínio primário dos seus agentes.

Não é um detalhe técnico. É uma decisão sobre o que os agentes SAP conseguem fazer em processos reais.

Fechar o trimestre envolve dezenas de decisões encadeadas: validar entradas, identificar inconsistências, aplicar regras de reconciliação, escalar para os aprovadores certos, registrar cada passo. Um modelo que só executa a próxima ação óbvia falha quando o processo desvia do fluxo padrão — que é quando os problemas reais aparecem.

O Claude foi escolhido pela capacidade de raciocínio em múltiplos passos: ele mantém contexto ao longo de uma cadeia de decisões, avalia consequências antes de agir e reconhece quando precisa escalar para um humano.

Três pontos que valem atenção:

→ Claude opera dentro dos controles SAP — aprovações, alçadas, políticas de acesso — não ao lado deles
→ A plataforma SAP é multi-LLM: Anthropic, OpenAI, Google, NVIDIA — empresas escolhem qual modelo processa cada tipo de dado
→ SAP e Anthropic estão desenvolvendo agentes customizados para setores específicos: saúde, setor público, utilities, educação, ciências da vida

O detalhe que a maioria ignora: o Claude é tão preciso quanto o contexto que o alimenta. Esse contexto vem do SAP Business Data Cloud. Empresas com BDC bem estruturado chegam à parceria prontas para aproveitar. Empresas com dados fragmentados chegam com um obstáculo antes mesmo de ativar o primeiro agente.
