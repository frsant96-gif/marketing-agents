## Personas

### Decisor Principal — CIO / Diretor de TI

| Campo | Conteúdo |
|---|---|
| **Cargo / Área** | CIO, Diretor de TI, VP de Tecnologia |
| **Papel na decisão** | Decisor |
| **Indústria / Porte** | Cross industry — empresas com SAP implantado, faturamento acima de R$ 800M |
| **Desafios principais** | Dados espalhados em SAP + múltiplos sistemas externos sem integração; pressão para entregar IA mas sem infraestrutura pronta; governança de dados inexistente ou frágil; ROI difícil de justificar em projetos de dados longos; múltiplas iniciativas em paralelo sem resultado concreto |
| **Motivação para compra** | Ver IA funcionando sobre os dados reais da empresa sem construir do zero; reduzir time-to-value de projetos de dados |
| **Barreiras / Objeções** | "Nosso ambiente é muito complexo para integrar"; "já temos iniciativas em andamento"; custo percebido alto; medo de mais um projeto longo sem resultado |
| **Restrições** | Governança e compliance de dados; aprovação orçamentária com CFO |

## Oferta — SAP Business Data Cloud (BDC)

| Campo | Conteúdo |
|---|---|
| **Solução ofertada** | SAP Business Data Cloud (BDC) — implementado pela Solveplan |
| **Problema que resolve** | Dados fragmentados entre SAP e non-SAP impedem o uso real de IA; empresas têm os dados mas não conseguem ativá-los |
| **Benefícios técnicos** | Camada unificada e governada de dados; integração nativa com S/4HANA; conectores para fontes non-SAP; modelo semântico compartilhado |
| **Benefícios de negócio** | IA nativa (SAP Joule) sem construir infraestrutura do zero; time-to-value mais rápido; governança de dados sem projetos paralelos |
| **Diferencial Solveplan** | Melhor Parceiro SAP BDC 2026 — América Latina (SAP Partner Awards); aceleradores próprios; 390+ projetos entregues; 150+ empresas atendidas; 60+ especialistas SAP; 13+ anos de atuação |
| **Cases** | A confirmar — candidatos: VALE, Klabin, Aegea, COPEL |
| **Pontos restritivos** | Não mencionar preço sem qualificação; não comparar diretamente com Databricks/Snowflake sem contexto adequado; não dar prazo de implementação sem assessment |
| **Palavras-chave** | SAP BDC, Business Data Cloud, dados SAP, IA para dados corporativos, governança de dados SAP, unificação de dados, SAP Joule, analytics integrado |
