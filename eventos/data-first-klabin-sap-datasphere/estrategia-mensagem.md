## 1. Persona

### Persona principal — Decisor: CIO / Diretor de TI

| Campo | Descrição |
|---|---|
| **Cargo / Área** | CIO, Diretor de TI, VP de Tecnologia |
| **Papel na decisão** | Decisor |
| **Indústria / Porte** | Cross-industry, empresas de médio/grande porte, usuárias SAP |
| **Desafios principais** | Pressão para "entregar IA" sem infraestrutura de dados pronta; dados fragmentados entre SAP e sistemas externos; iniciativas de IA abandonadas antes de chegar à produção (42% das empresas, segundo Gartner/S&P); ambiente Datasphere crescendo sem governança |
| **Motivação para compra** | Não quer ser a estatística dos 42% que abandonam IA; precisa mostrar resultado de IA ao board sem expor a empresa a risco de decisão automatizada errada |
| **Barreiras / Objeções** | "Já implementamos o Datasphere, achamos que está resolvido"; receio de mais um projeto de consultoria sem ROI claro; ceticismo com promessas de IA |
| **Restrições** | Aprovação orçamentária corporativa; compliance e segurança de dados; dependência de TI interna sobrecarregada |

### Persona influenciadora — Head de Dados / Head de Analytics / BI

| Campo | Descrição |
|---|---|
| **Cargo / Área** | Head de Dados, Head de Analytics, Gerente SAP, Arquiteto de Dados, Líder de BI |
| **Papel na decisão** | Influenciador técnico |
| **Indústria / Porte** | Empresas SAP com times de dados estruturados |
| **Desafios principais** | Time sênior gasta 2 dias por semana "apagando incêndio" em vez de construir; falhas de carga que levam até 15h para serem detectadas; 52% do armazenamento Datasphere sem uso real; ambiente cresce sem dono por objeto |
| **Motivação para compra** | Recuperar tempo do time para entregar valor, não sustentação; ter visibilidade e controle sobre o ambiente Datasphere; provar ao CIO que a fundação está pronta para IA |
| **Barreiras / Objeções** | "Isso é function interna, não terceirizamos governança"; medo de perder controle do ambiente para terceiro |
| **Restrições** | Processos internos de mudança (change management); política de dados da empresa |

### Persona secundária — Responsável por Transformação Digital

| Campo | Descrição |
|---|---|
| **Cargo / Área** | Diretor/Gerente de Transformação Digital |
| **Papel na decisão** | Influenciador de negócio |
| **Indústria / Porte** | Empresas em jornada de modernização, cross-industry |
| **Desafios principais** | Cobrança por resultados de IA em prazo curto; dificuldade de conectar iniciativas de dados a resultado de negócio mensurável |
| **Motivação para compra** | Case de sucesso replicável (Klabin) que dá segurança para levar ao board |
| **Barreiras / Objeções** | Ceticismo com "mais um case bonito que não se aplica à minha realidade" |
| **Restrições** | Orçamento sob orçamento de outras áreas (TI, dados) |

## 2. Oferta

| Campo | Descrição |
|---|---|
| **Solução ofertada** | SAP Datasphere / SAP Business Data Cloud (BDC), com Solve Watch (serviço gerenciado de cuidado contínuo da fundação) como CTA principal via Diagnóstico do ambiente Datasphere |
| **Problema que resolve** | Fundação de dados sem governança que trava projetos de IA — qualidade de dados, controle de risco e valor de negócio (3 das 4 causas de abandono de projetos de IA, segundo Gartner, vivem na fundação, não no modelo) |
| **Benefícios** | Camada semântica governada (Knowledge Graph); redução de até 70% em custo de tokens de IA com fundação bem construída; detecção de falhas em 1 dia (vs. 15h+ sem monitoramento); redução de CU/custo de armazenamento; IPIA (Índice de Prontidão para IA) como métrica contínua de saúde do ambiente |
| **Diferencial** | Melhor Parceiro SAP BDC da América Latina (SAP Partner Award 2026); SAP Gold Partner especializado em Data & Analytics; +200 clientes, +400 projetos, +600 mil horas; não é só implementação — é cuidado contínuo da fundação com Solve Watch (agentes vigiam, arquiteto valida, cliente decide) |
| **Cases** | Klabin (case principal do webinar — confirmar autorização de uso de nome, dados e citações antes da divulgação); referências adicionais: Hospital Israelita Albert Einstein (3min de folha), Vale (186 empresas consolidadas), Zilor (6 meses planejamento agrícola) |
| **Pontos restritivos** | Não abordar preço sem qualificação; não comparar tecnicamente com Databricks/Snowflake fora de contexto (são complementares via Delta Sharing, não concorrentes); não fazer promessa de prazo/resultado específico do case Klabin sem validar com o cliente o que pode ser público |
| **Palavras-chave** | SAP Datasphere, SAP Business Data Cloud, BDC, fundação de dados, Data-First, IA agêntica, governança de dados, Knowledge Graph, Delta Sharing, IPIA, Solve Watch, prontidão para IA |
